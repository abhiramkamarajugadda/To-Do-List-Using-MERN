# To-Do List Application (MERN Stack)

A full-stack task manager with a React (Vite) frontend, a Node.js and Express REST API, and MongoDB storage through Mongoose.

## Features

- Add, list, complete or reopen, and delete tasks
- Live counters for total, pending and completed tasks, with All, Pending and Completed filters
- Input validation on the API (`taskName` is required, 400 on empty input)
- Tasks sorted newest first
- Vite dev server proxy to the API, so the frontend calls `/api/tasks` directly
- MongoDB Atlas or local MongoDB through `MONGODB_URI`, with an in-memory MongoDB fallback (`mongodb-memory-server`) for quick demos
- Helper scripts: an automated API test (`test-api.js`), a database viewer (`view-mongo-tasks.js`) and a Postman collection

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 19, Vite 6, Axios, Lucide React, CSS |
| Backend | Node.js, Express 4, CORS, dotenv |
| Database | MongoDB, Mongoose 8 |
| Tooling | nodemon, concurrently, Postman collection |

## REST API

Base URL: `http://localhost:5000/api/tasks`

| Method | Endpoint | Description | Body | Success |
|---|---|---|---|---|
| GET | `/api/tasks` | List all tasks, newest first | None | 200 |
| POST | `/api/tasks` | Create a task | `{ "taskName": "string" }` | 201 |
| PUT | `/api/tasks/:id` | Update a task | `{ "isCompleted": true }` | 200 |
| DELETE | `/api/tasks/:id` | Delete a task | None | 200 |

## Database Schema

Collection `tasks` in database `todo_db`:

| Field | Type | Notes |
|---|---|---|
| `_id` | ObjectId | Generated by MongoDB |
| `taskName` | String | Required, trimmed |
| `isCompleted` | Boolean | Default `false` |
| `createdAt` | Date | Default `Date.now` |

## Getting Started

**Prerequisites:** Node.js 18 or later; MongoDB locally or a MongoDB Atlas cluster (optional, thanks to the in-memory fallback).

```bash
git clone https://github.com/abhiramkamarajugadda/To-Do-List-Using-MERN.git
cd To-Do-List-Using-MERN
npm run install:all
cp server/.env.example server/.env    # then set MONGODB_URI
npm run dev
```

- API: `http://localhost:5000`
- Frontend: `http://localhost:3000`

Run the API test script with `npm run test:api` while the server is running.
